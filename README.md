## What I'm working on

- **GenAI ETL automation:** turning natural-language mapping rules into production PySpark and Scala on AWS Glue. It cut engineering effort by 70%+ and delivery time from about 5 months to 4 weeks.
- **Agentic data mapping:** a human-in-the-loop ReAct agent with enterprise MCP tools that proposes and refines source-to-target mappings, reaching 75% source-field recall on cross-domain benchmarks.
- **LLM evaluation:** benchmarking open and frontier models on accuracy, latency, hallucination rate and cost, then feeding the results back into prompts and configuration.
- **My own agent platform:** a self-hosted setup of sandboxed headless Claude Code workers, independent verification and browser agents, with a human approval step.
